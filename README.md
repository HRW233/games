# Arcade Club

**Play it here: https://hrw233.github.io/games/**

Eighteen browser games on one shelf: twelve from GitHub collections and six quick club originals. The GitHub Pages workflow publishes a static snapshot of the Arcade Club site, including its self-hosted fonts and the seven local game pages. The remaining carts stream from their original GitHub hosts, just as they do on the main site.

## How it works

- `Deploy Arcade Club` fetches the 17 static files from the live Arcade Club site.
- The files are uploaded as a GitHub Pages artifact and deployed to `hrw233.github.io/games/`.
- Pushing to `main` or running the workflow manually refreshes the copy.

## Privacy

The arcade has no accounts and no first-party tracking. External game collections may set their own storage or cookies. See the [privacy note](https://hrw233.github.io/games/privacy.html) for details.
